# Contributing to Constella

- Start a Discussion for pilots/new docs.
- Keep PRs small; link an Issue/Discussion.
- Mark claims with a confirmability tier: **confirmed**, **asserted**, or
  **speculative** — see [`docs/reference/confirmability.md`](docs/reference/confirmability.md),
  which is canonical for the whole ecosystem. (This line previously read
  "stable, contested, or speculative"; that vocabulary predates the schema and was
  never reconciled. Corrected 2026-07-31.)
- CI must pass: links + spellcheck.
